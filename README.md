# lemma-scoop

个人 Scoop bucket,收录常用工具与部分中国版软件。

## 使用

```powershell
scoop bucket add lemma-scoop https://github.com/wanzhao-ysy/lemma-scoop
scoop install lemma-scoop/<app>
```

| App | 说明 |
| --- | --- |

| bettergi | BetterGI · 更好的原神 |
